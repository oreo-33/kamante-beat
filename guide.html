📖 あそびかたガイド

玉利の鎌手踊りを、あそびながら知って、好きになろう！

🌟 はじめての人へ

  1. ホームの、大きな「かまんてリズム」をおして あそぼう。
  2. ゲームをあそぶと、🎫チケットがたまるよ。
  3. チケットで「福引」をひいて、おたからを集めよう。
  4. わからなくなったら、ホームの「もっと」→「説明」で、このページにもどれるよ。
ホーム リズム ラン パズル 福引 図鑑 育成 歴史 ミッション ログイン せってい こまったとき かまんてとは
🏠 ホーム画面の見かた
  • いちばん上: あなたの名前と、🎫チケットの数。「ログイン」をおすと、記録がのこせます。
  • 大きな写真: 下に「かまんてのひとこと」が出ます。さわると、つぎの豆知識になります。
  • かまんてリズム: いちばんのおすすめ。ベストスコアも出ます。
  • かまんてラン・かまんてパズル: ミニゲームです。
  • 下のバー: 福引 / 育成 / 歴史 / ランキング / もっと
  • 「もっと」の中: きょうのごほうび / ミッション / おたから図鑑 / 練習動画 / 説明 / 文字の大きさ
💡 ホームを開いたとき、「きょうのごほうび」が出たら、「うけとる！」をおそう。毎日🎫がもらえます。
🥁 かまんてリズム

鎌手踊りの動画が背景に流れます。光る輪が、マスにぴったり重なる瞬間に、そのマスをタップ！

あそびかた

  1. 「やさしい」か「ふつう」をえらんで、START。
  2. マスの上に、赤い輪が出て、ゆっくり小さくなります。
  3. 輪が白い丸に重なったら、そのマスをタップ。

はんてい

はんてい いみ
すばらしい(PERFECT) ぴったり！いちばん高い点
いいね(GREAT) ほぼぴったり
おしい(GOOD) すこしズレた

つづけて成功するとコンボで、点がふえます。あなたがおしたマスが ちがっても、ペナルティはありません。

💡 輪の動きを見て、「ここだ！」と思う前に、すこし先を読んでタップすると うまくいきます。タップした音が出るので、リズムにのってみよう。

🎫チケット: 4〜12まい(成績によって)。結果画面には、スコアと、あなたのクセも出ます。

🏃 かまんてラン

お祭りに向かって走る、ランゲームです。障害物をよけて、🪙をあつめよう。

そうさ

  • 画面の上をタップ または ⬆️ボタン = ジャンプ。空中でもう一回で、2だんジャンプ。
  • 画面の下をタップ または ⬇️ボタン = しゃがむ。
  • パソコンは、スペースキー(ジャンプ)と、↓キー(しゃがむ)。

障害物(しゅるいがいっぱい)

  • 竹・太鼓・たる・転がる太鼓・火の玉・穴 → ジャンプで越える
  • 提灯・幟・鳥居 → しゃがんでくぐる
  • 高い石灯籠 → 2だんジャンプ
  • 鳥 → ジャンプでも、しゃがみでもOK

はじめて出る障害物には、🆕のヒントが出ます。

アイテム

  • 🌟 むてき(障害物をふっとばす)　🧲 コインよせ　🍙 コイン2ばい　❤ かいふく　💎 ダイヤ(+100点)
  • 🪙をつづけて取るとコンボ。30コンボで🔥FEVER（コイン2ばい）！

モードと腕前

  • やさしい: ハート3つ。　ふつう: 1回当たったら終わり。
  • あそぶたびに腕前(Lv)が上がり、だんだんむずかしくなります。
💡 画面の向きは、よこむきのほうが、遠くまで見えてあそびやすいです。右上の音ボタンで、BGMあり・効果音だけ・なしを切りかえられます。

🎫チケット: 3〜15まい(＋ミッションの分)。結果画面に、1回ごとの3つのミッションが出ます。

🧩 かまんてパズル

バラバラのピースを並べて、写真を完成させよう。

  • やさしい 20ピース / ふつう 48ピース / むずかしい 100ピース

ピースの置きかた(どちらでもOK)

  1. タップ: 下のピースをタップ → 光ったところをタップ。
  2. ドラッグ: ピースを指でひっぱって、場所に近づけて はなす。

まちがった場所には、置けません(ぷるっとゆれるだけです)。

べんりなボタン(上の列)

  • 💡 ヒント: つぎのピースを光らせます(かわりに +10秒)。
  • 🖼 完成図　👻 うっすら完成図　➕➖ 大きさ　🔊 音　🚪 やめる

はやく完成するほど、⭐が多くもらえます(最大3つ)。🎫チケットは、5・8・12まい(＋⭐の分)。

🎰 おたから福引

🎫チケットを使って、お祭りの「おたから」を引こう。

  1. 「たんぱつ」(1まい) または「10れん」(10まい)をえらぶ。
  2. 出てきた太鼓を3回タップ！
  3. カプセルが出るよ。色で、中身のレア度がわかります。タップして あけよう。

📚 おたから図鑑

引いたおたからが、絵と説明つきでのこります。ぜんぶで26しゅるい。まだ見つけていないものは、黒い かげで出ます。

ダブったおたからの使いみち

  • 🙏 ほうのう: 育成キャラの経験値になります。
  • 🎫 こうかん: チケットにかえられます。
  • ※ どちらも、1こは図鑑にのこります。

ほうび・しょうごう

図鑑を5・10・15・20・26しゅるいそろえると、🎫がもらえます。しゅるいごとにそろえると、称号👑ももらえます。称号は、えらぶと、ホームに出ます。

🗺️ 歴史モード「かまんて探訪」

夕暮れの玉利の里を、3Dで歩きながら、かまんて踊りの物語をたどります。道宮先生が案内してくれます。

そうさ

  • 📱 スマホ・タブレット: 左下をなぞると歩く、右側をなぞると見まわす。
  • 💻 パソコン: W A S Dで歩く、マウスのドラッグで見まわす。
  • ボタンが出たらタップ（「はなす」「ともす」「たたく」「よむ」など）。
  • 🧭 自動で歩く: おすと、目的地まで歩いてくれます。
  • 右上のミニ地図と、左上の矢印が、行き先を教えてくれます。光の柱が目印です。
  • ⚙ せってい: 見まわす はやさ・文字の大きさ・カメラ演出・画質(ふつう/きれい)

5つの章

  1. 権現神社: 石灯籠5つに あかりをともす
  2. 静かな広場: 記憶のかけらを6つ あつめる
  3. 古い蔵: 古い資料の巻物を4つ さがす
  4. つなぐ広場: たいこを拍に合わせてたたく
  5. お祭り広場: わすれの影と戦う

よりみちも楽しもう

  • 📖 石碑(8つ): 近づいて「よむ」と、豆知識が「ひとことずかん」にたまります。
  • 🪙 かくれ小判(8つ): 里のすみにかくれています。
  • 💬 むらびとに話しかけてみよう。

🎯 ミッション

「福引を1回ひく」「パズルをクリア」などの目標をクリアすると、🎫と称号がもらえます。「うけとる！」をおして、受け取ろう。

📅 きょうのごほうび

毎日ひらくと、🎫がもらえます(1日め〜7日め)。1日お休みしても、つづきからOK。

🎬 練習動画

  • 🐢 はやさをえらべます(ゆっくり ×0.5 など)。
  • 🪞 左右はんてん: 鏡のように まねしやすくなります。
  • 📍🏁 ここから・ここまで: むずかしいところを くりかえし。
  • 1分見ると、🎫3まい(1日1回)。
🏆 ランキング・ログイン
  • ログインしなくてもあそべます(ゲスト)。ランキングにのるには、ログインが必要です。
  • 新規登録: ホームの「ログイン」→ ID(ニックネーム)とパスワードを入れて「新規登録」。
  • IDは3〜16文字。ひらがな・カタカナ・漢字・英数字・＿ が使えます。
⚠️ ランキングに名前が出ます。本名・学校名・住所は入れないでね。パスワードはわすれないようにメモしておこう(メールがないので、再設定できません)。
  • ランキングは、リズム・ラン・パズル(3つの難しさ)ごとに見られます。自分の順位と、「ひとつ上まであと何点」も出ます。
  • やめたいときは、ログイン後に「退会」をおします(記録はすべて消えます)。

チケット・キャラ・図鑑のデータは、この端末のブラウザにほぞんされます。ブラウザのデータを消したり、べつの端末にかえると、もどりません。

🔊 おと・もじ・画面のせってい
  • 🎵 BGM: 画面の左下のボタンで オン・オフ。ページを開いて、最初に1回タップすると鳴り始めます。
  • 📱 iPhone・iPad: 本体の消音スイッチをOFFにしてね。
  • 🔠 文字の大きさ: ホームの「もっと」→「文字の大きさ」。このページの上にも あります。
  • 🎮 ランの音: 右上の音ボタンで、BGMあり・効果音だけ・なし。
  • 🗺️ 歴史モード: ⚙で、見まわす はやさ・画質などを かえられます。
❓ こまったとき

音が出ない

ページを開いて、一度画面をタップしてください。iPhone・iPadは、消音スイッチをOFFに。左下の🎵が「🔇」になっていたら、おして切りかえます。

歴史モードが開かない / 3Dが出ない

インターネットにつながっているか、確認してください(3Dの部品を読みこむため)。古い端末では動かないことがあります。

動きが重い・カクカクする

歴史モードの⚙で、画質を「ふつう」にして、「カメラ演出」を OFF に。ほかのアプリを閉じるのも効果的です。

画面がずれる・文字が小さい

ホームの「もっと」→「文字の大きさ」で、大きくできます。スマホは、たてもち・よこもち、どちらでも使えます。

チケットが足りない

ゲーム(1日6回まで満額)・きょうのごほうび・練習動画・ミッションで、ためられます。

データが消えた

ブラウザに保存しているため、ブラウザのデータを消すと もどりません。同じ端末・同じブラウザで あそんでください。

🏮 玉利の鎌手踊りとは
  • 鹿児島市下福元町の玉利集落に、約240年前から伝わる踊りです。
  • 豊作と無病息災を祈って、踊られてきました。
  • 踊り手は、「鎌」の6人と「棒」の6人。歌に合わせて、鎌と棒をはげしく打ち合わせるのが見どころです。
  • いちど とだえましたが、地域の人たちの手で、よみがえりました。
  • 今は、高校生たちが授業で練習し、小学校や施設で披露して、次の世代へつないでいます。

このアプリは、遊びながら、この踊りを知って、好きになってもらうために作られました。
